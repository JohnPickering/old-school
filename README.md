Old Schools is a very dumb text editor aimed at mimicking an typewriter.  This is deliberate.  It is intended for teachers to help them defeat the use of AI (LLMs) by students on assignments.  No text can be copy or pasted into Old School. There is no spell checker or predictive text. The output is simply a pdf. Because the text is first converted to an image before adding to the pdf it cannot be easily changed by an external pdf editor. 
While teachers may wish to allow students to use this while they are still connected to the internet (simply by giving them the link https://JohnPickering/old-school) it can be downloaded as an html file and the file put on any computer for running with the internet access switched off.
This has been tested in multiple browsers (Chrome, Edge, Safari, Firefox) on Windows, Linux, and MacOS.  The "Save As..." button works a little differently according to browser and operating system. Sometimes it directly save a file "Old_school_Assingment.pdf" into the downloads folder. Other times, a dialogue box is opened allowing the student to save to a location.
There is some hidden text which helps identify the origin of a pdf.
